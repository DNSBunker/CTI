# is never listed; a listed one leaves at its next recheck.
# One IP or CIDR network per line, '#' starts a comment. Changes are live
# within ~1 minute.
#
# NEVER add shared addresses (CDNs such as Cloudflare 104.16.0.0/13 or
# 188.114.96.0/20, Vercel, AWS, hosting providers, parking services like
# 13.248.169.48 / 76.223.54.146): thousands of malicious sites share them.
# tif refuses private/loopback/reserved ranges and anything broader than
# /16 (IPv4) or /32 (IPv6).
#
# Feed below: addresses that serve no websites at all - public DNS
# resolvers and the DNS root servers. Malware operators "park" inactive
# command-and-control domains on them (like 0.0.0.0): nothing reachable
# there, so nothing to block.
